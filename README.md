# Paper Scout

Paper Scout — приложение для поиска и анализа научных публикаций о долговременной памяти AI-агентов. Go API выполняет исследования, Flutter-клиент для Android показывает результаты и управляет личной библиотекой.

## Возможности

- Поиск статей в arXiv и загрузка доступного полного текста из HTML или PDF.
- Анализ текста и отчёты на русском со ссылками на исходные фрагменты. Приложение различает полный, частичный анализ и анализ только аннотации; изображения и сканы без текстового слоя не распознаются.
- Уточняющие вопросы и гибридный поиск по библиотеке: BM25 + Qwen3 embeddings + RRF.
- Память между диалогами: сохранение выводов, автоматический поиск прошлых исследований и сравнение с новыми работами с указанием источников.
- Личные заметки, исправления и исключение устаревших сведений из памяти.
- История диалогов, сохранённые статьи, отметки о прочтении и профиль интересов. Два аккаунта имеют отдельные данные.

## Локальный запуск

Нужны Go 1.26+, Flutter с Android SDK и эмулятором, Poppler (`pdfinfo`, `pdftotext`), работающая Ollama с моделью `qwen3-embedding:0.6b` и ключ DeepSeek API. Команды выполняются из корня репозитория.

### Сервер

Создайте `.env` на основе [.env.example](.env.example). Укажите `DEEPSEEK_API_KEY`, доступную вашему аккаунту модель в `DEEPSEEK_MODEL` и добавьте настройки двух пользователей:

- `SEED_USER_1_LOGIN`, `SEED_USER_1_PASSWORD`;
- `SEED_USER_2_LOGIN`, `SEED_USER_2_PASSWORD`.

Логины должны различаться, длина каждого пароля — от 12 до 72 байт UTF-8. Ключи и пароли остаются на сервере и не передаются во Flutter.

```sh
mkdir -p bin
go build -o bin/paper-scout ./cmd/paper-scout
./bin/paper-scout -seed -env-file .env
./bin/paper-scout -env-file .env
```

По умолчанию API доступен по `http://127.0.0.1:8080`, Ollama — по `http://127.0.0.1:11434`. Команда `-seed` создаёт отсутствующие аккаунты, сохраняя существующие. SQLite и кэш статей находятся в `data/` и сохраняются после перезапуска.

### Android-клиент

Запустите эмулятор. В другом терминале выберите его идентификатор из `adb devices` (в примере — `emulator-5554`):

```sh
adb devices
export SCOUT_DEVICE=emulator-5554
adb -s "$SCOUT_DEVICE" reverse tcp:8080 tcp:8080
cd client
flutter pub get
flutter run -d "$SCOUT_DEVICE" --dart-define=API_BASE_URL=http://127.0.0.1:8080
```

Если изменили `HTTP_ADDR` в `.env`, используйте тот же порт в `adb reverse` и адресе API. Адрес также можно изменить на экране входа.

Войдите одним из созданных аккаунтов, создайте диалог и задайте исследовательский вопрос. Результаты, источники и заметки доступны в истории и библиотеке. После остановки приложения потребуется войти снова; серверные данные сохранятся.

Подробная конфигурация и команды обслуживания: [локальный запуск](docs/local-development.md).
