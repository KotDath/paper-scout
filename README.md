# Paper Scout

Paper Scout — персональный исследователь публикаций о долговременной памяти AI-агентов. Пользователь задаёт исследовательский вопрос, помощник ищет реальные статьи, читает доступные полные тексты и сохраняет отчёт с проверяемыми ссылками на источники.

Цель первой версии — рабочий локальный прототип для **дня 35**: показать реальную задачу, участие AI и полный рабочий процесс на видео с эмулятора. **День 33 исключён по решению пользователя; день 34 в объём не входит.**

Реализована основа Go-сервера T01: конфигурация, SQLite, миграции, `/healthz` и `/readyz`. Проверенные команды — в [инструкции foundation](docs/foundation.md). Исследовательский API и Flutter-приложение ещё не реализованы; остальные интерфейсы являются планом реализации.

T02 добавляет [два аккаунта и профили](docs/accounts.md): идемпотентный seed,
вход/выход и bearer-сессии с изоляцией по владельцу. Фактические проверки
записаны в [результате T02](docs/verification/T02.md).

## Принятые ограничения

- Go API и Flutter-приложение; Android-эмулятор используется для проверки и записи видео.
- Управление устройством и взаимодействие с интерфейсом приложения при проверках и демонстрации — через `claude-in-mobile`.
- Локальный запуск на ноутбуке, два заранее созданных аккаунта с изолированными данными.
- DeepSeek Chat Completions API, собственный agent harness и сохранение истории на сервере.
- Агентные библиотеки запрещены. Обычные HTTP, SQL, HTML/PDF и Flutter-библиотеки допустимы.
- Юнит-тесты запрещены. Интеграционные и реальные сквозные проверки разрешены.
- Чтение полного доступного текста без OCR. При недоступности полного текста — явный режим «только аннотация».
- Гибридный RAG: BM25 + локальные эмбеддинги `qwen3-embedding:0.6b` через Ollama + RRF.
