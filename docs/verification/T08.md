# T08 — индексация и гибридный retrieval

Дата: 2026-10-18. Worktree: `paper-scout-worktrees/T08`, ветка `dag/t08`.
Base: `bea14f91abb33b16c847d14e511e8f7d361e9f2d`.

## Результат

Реализованы FTS5/BM25, exact cosine по 1024-мерным векторам и RRF с k=60;
owner-фильтр обеих веток применяется до top-20. Итоговый контекст: до восьми
целых chunks / 16000 Unicode-символов, с удалением сильных перекрытий.
Добавлены стабильное разрешение evidence, HTTP search/evidence с настоящей
авторизацией, документный vector cache и сохранённый прогресс индексации.
Ни индексация, ни retrieval не отмечают статью прочитанной/проанализированной.

Контракт для T11 и последующих узлов: [../retrieval.md](../retrieval.md).
`user_papers` принадлежит миграции T08; importer создаёт membership через
`AddPaper` для серверного владельца run. Дублировать эту таблицу не требуется.

  поиск без авторизации — 401. Невалидные лимиты/пустой запрос — 400.
- Произвольный синтаксис FTS безопасно превращается в буквальные токены.
  Scope из более чем 20000 chunks отклоняется до query inference.
- Повторная индексация использовала все 12 векторов без `/api/embed`.
  Дополнительный evidence ID с тем же точным входом переиспользовал публичный
  кэш без inference; одинаковый диапазон не задублировался в контексте.
- Несовместимые model ID/digest, encoding, chunking и input hash исключены из
  dense и дают `hybrid_partial`; повреждённый zero-vector также исключён.
- HTTP 503 инъецировался только в loopback proxy перед настоящей Ollama;
  общий сервис не останавливался. Поиск вернул `lexical_only` с причиной
  `embedding_unavailable`, доступным BM25 и без dense-кандидатов.
  Изменение заголовка сбросило сохранённый `ready` в `pending`; перед ready
  входы перепроверяются в транзакции. Изменение заголовка из HTTP boundary

  Index сохранил `partial` при 11 готовых chunks и `failed` при полностью
  изменённом входе; восстановление backend позволило завершить индекс.
- Перезапуск SQLite/HTTP сохранил membership, bearer-сессии, векторы,

## Границы доказательств

Это live-проверка retrieval/backend на синтетическом корпусе, без arXiv download,
DeepSeek, отчёта или Flutter. Проверка цитирования реального ответа по настоящей
статье и сквозной UI-сценарий относятся к T11–T16 и здесь не заявляются.
Смена модели требует нового клиента и переиндексации. Если startup preflight
не смог создать клиент, восстановление полного hybrid требует перезапуска Go.

Подробные ранги всех веток сохранены локально в игнорируемом
`.bb/runtime/t08/retrieval-evaluation.json`; runtime, БД, bearer tokens и кэши не
включены в Git. Dotenv-файлы не читались/не печатались агентом; live-проверка
использовала локальную Ollama без платных вызовов.
