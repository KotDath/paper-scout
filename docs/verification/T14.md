## Реализация

- Диалоги с созданием, пагинацией и сохранённой публичной историей; вопрос и
  follow-up используют один диалог. Run admission сохраняет request ID и текст
  при неоднозначной транспортной ошибке; повтор отправляет тот же запрос.
- Polling раз в секунду без перекрывающихся запросов; возрастающий event cursor,
  пагинация сообщений/событий, pause в фоне и обновление при возвращении.
  Реальные события, отмена, terminal/error states, источники и coverage.
- Отчёт с исходным Markdown, отдельными кнопками citations и источников;
  evidence показывает исходный текст, Unicode range, страницу/раздел и ссылку,
  открываемую Android-браузером через url_launcher. Приватные trace не читаются.
- Анализ complete/partial/abstract_only/none, extraction и index status разделены.
  Доступен отчёт каждого завершённого запуска; отсутствие отчёта явно показано.
  Длинные сообщения раскрываются, чтобы не скрывать состояние и управление.
- Библиотека, saved/read, явное сохранение заметки, профиль интересов; поиск
  фрагментов показывает retrieval mode, обе ветки, RRF ranks и причины деградации.
- Вложенные ресурсы остаются внутри account-keyed дерева Flutter; logout/401
  удаляет экраны и controller/timers. Токен по-прежнему только в памяти.
- Проверка клиента переиспользует bounded composition и fixtures T12/T11,
  не вводит новые серверные сущности, agent libraries или unit/widget tests.
