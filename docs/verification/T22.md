## Исправления по фактической приёмке

Production `cmd/paper-scout` использует один существующий AgentRunner/DeepSeek
client с исполняемым final contract до report commit: scoped E/M/Q handles,
точные canonical IDs, owner checks, successful primary reads и exact excerpts.
Один bounded repair входит в общий request/token/cancel/deadline budget.
Повторная неудача не публикует scientific report. Private rejected drafts не
попадают в accepted replay; canonical final/history/report принимаются атомарно.

User notes/corrections выводятся сервером дословно и отдельно от научных
выводов; materially used claim/note включает доставленные direct, transitive
и report-level corrections. Feedback не становится научной истиной.
Scoped catalog не является inventory, его metadata входят в memory budget.
JSON Output/temperature=0 применены через тот же клиент, не второй agent loop.
Analyzer получает object-shape example с настоящим evidence ID.
Flutter дополнительно показывает фактические запросы/токены/tools и отдельно
unknown usage; последнее изменение проверено новым APK и UI на прежнем run.
Контракт: [research-memory.md](../research-memory.md#t22-исполняемый-контракт-принятия-ответа).
