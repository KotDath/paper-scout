# T13 — Flutter shell, API client and login

Date: 2026-10-18. Branch: `dag/t13`. Base:

## Implementation

- Android-only Flutter app in `client/`, Russian login and account screens.
- Go API origin comes from `API_BASE_URL` or the editable login field.
- Shared Dart transport: JSON, bearer header, no redirects, bounded response size,
  connection/request deadlines, sanitized network/HTTP/protocol errors.
- Actual `/api/v1/auth/login`, `/me`, `/auth/logout` contracts from T02.
  Login 401 displays a credential error; protected 401 clears the account/token
  and returns to login. Session check also runs when the app resumes.
- Credentials are not persisted or logged. Token stays in process memory;
  app restart requires login. Server logout revokes the token before local
  session removal; failed network logout can be retried. Per-account screens
  are keyed by server user ID and discarded when the account changes.
- Local HTTP allowed only for Android debug. Internet permission is present in
  main; backups disabled. `client/README.md` has build/run instructions.
- No research screens, agent dependencies, provider calls, migrations or unit/
  widget tests added. Go source and existing contracts unchanged.
