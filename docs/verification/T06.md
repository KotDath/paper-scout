## Scope and limitations

T06 acceptance covers real batch/query encoding, 1024 finite values, model and
digest verification, and explicit context overflow: met. Full hybrid search,
vector persistence/cache/chunking version, ownership filtering and retrieval
quality are T08 and later nodes and are not implemented or claimed here.

Ollama's API does not bind the inference response atomically to the manifest
digest. Checks detect observed changes before/after each operation; a tag
changed and restored entirely between checks cannot be detected. Avoid model
replacement while indexing; intentional updates require a new client and
reindexing. Upgraded Ollama template/encoding behavior requires another
compatibility check. No live dependency gaps remain for T06.
