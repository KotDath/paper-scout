# T01 — Go foundation и SQLite

Дата проверки: 2026-10-18. Ветка: `dag/t01`.
Base: `0fae8684f04899f4f35685e6997d11522a39471a`.

Результат: entrypoint `cmd/paper-scout`, безопасная загрузка явно указанного
dotenv, loopback HTTP, graceful shutdown, SQLite через `database/sql` и
`modernc.org/sqlite v1.60.1`, embedded task migrations с SHA-256 ledger.
Новых доменных таблиц нет: их создадут следующие DAG-ноды.
Команды и интерфейсы расширения описаны в [foundation.md](../foundation.md).

Проверено на `go1.26.2-X:nodwarf5 linux/amd64`:

- `go mod tidy`: успешно; зависимости зафиксированы в `go.mod`/`go.sum`.
- `go mod verify`: `all modules verified`.
- `go vet ./...`: успешно с локальными caches внутри `.bb/runtime/t01/`.
- `python3 integration/foundation.py`: успешно. Скрипт выполняет `go build`,
  запускает реальный Go-процесс на `127.0.0.1:0` и использует временную БД
  внутри этого worktree, включая путь с пробелами и URI-спецсимволами.
- `/healthz` и `/readyz`: HTTP 200. Readiness действительно выполняет
  FTS5 insert/MATCH/BM25 через Go-драйвер; 16 параллельных запросов успешны.
  Проверены `foreign_keys=1`, `busy_timeout=5000`, `journal_mode=wal`.
- Проверены права новой БД `0600`, SQLite integrity check, создание cache dir,
  загрузка dotenv по пути и приоритет переменных окружения.
- SIGTERM завершает процесс с кодом 0; после повторного старта с той же БД
  ledger, checksum и время применения неизменны, проверочная строка сохранена.
- Отсутствие Poppler в PATH: `/readyz` HTTP 503 с явными false checks,
  `/healthz` остаётся HTTP 200.
- Изменённый checksum миграции: запуск завершается кодом 1, существующие
  данные и ledger не переписываются.
- Неверный адрес, bind на `0.0.0.0` и порт >65535 отклоняются. Ошибка парсера
  dotenv не раскрывает входную строку.
- `gofmt -l cmd internal` не выводит файлов; `git diff --check` успешен.
  Unit/widget tests не создавались.

Границы: наличие Poppler в PATH ещё не доказывает извлечение настоящей статьи
(T05). DeepSeek, arXiv, Ollama, auth/ownership и Flutter не проверялись в T01;
они принадлежат последующим нодам. Приватный shared dotenv не читался,
внешних платных вызовов и моков не было. Временные БД/бинарники удалены
интеграционным скриптом; caches остаются только в игнорируемом runtime-каталоге.
Два цикла ревью и упрощение выполняет координатор после этапа implement.

Upstream references: [SQLite driver](https://pkg.go.dev/modernc.org/sqlite@v1.60.1),
[dotenv loader](https://pkg.go.dev/github.com/joho/godotenv@v1.5.1).
