2026-10-18. Worktree: `paper-scout-worktrees/T10`, branch: `dag/t10`.
Base SHA: `3cc924211792d67f37eaa1c93006b6c27d350036`.
Role/stage: executor / implement. Result: **ready**. Два review cycle и упрощение выполняет

Реализован `research.Analyzer`, task-specific migration `T10_analysis.sql`,
исполняемые интеграционные проверки и [контракт T11](../full-text-analysis.md).
Анализатор передаёт весь извлечённый текст одним запросом или последовательными
пакетами, сохраняет точные входы/хеши, диапазоны и результат каждого шага,
синтезирует наблюдения, раскрывает исходные evidence с URL/section/page.
Coverage считается объединением только успешных reading ranges; synthesis
покрытия не добавляет. Техническое извлечение и глубина анализа разделены.

`run_sources` — единая новая сущность выбора источников; `analysis_segments`
связан с run/document через `paper_analyses`, чтобы вопросы и повторные попытки
не смешивали покрытие. Уже существующие users, runs, documents, chunks не
дублируются. AgentRunner/исследовательские tools/API/Flutter не реализованы
в этой ноде. Вызовы используют обязательный run-bound callback единого
DeepSeekClient; прямого провайдерного fallback нет.
