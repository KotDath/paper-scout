# T03 — DeepSeekClient

Дата: 2026-10-18. Worktree: `paper-scout-worktrees/T03`, ветка: `dag/t03`.
Base: `01131aba83491b196e75ace742625a2fad0c1d57`.

Реализован единый серверный `DeepSeekClient` на `net/http`: Chat Completions,
tools и coherent message replay, отдельный reasoning, usage, отмена/deadline,
sanitized errors, bounded responses. История и исполнение tools принадлежат
последующим нодам. [Контракт и команды](../deepseek-client.md).

## Интеграционный HTTP fixture

`python3 integration/deepseek.py` — PASS:

- POST `/v1/chat/completions`, Authorization и JSON; явные stream=false,
  thinking, max_tokens, tool_choice=auto; nullable assistant content;
  assistant/tool exchange с исходным ID и replay private reasoning;
  prompt/completion/total/cache usage.
- HTTP 400/401/402/422/429/500/503, Retry-After, классификация и отсутствие
  provider body/секрета в ошибке; ровно одна попытка; неизвестный usage.
- Redirect не выполняется; невалидный и >8 MiB response отклоняются;
  отсутствие/неполнота/несогласованность usage не превращается в ноль.
- finish=length возвращает ошибку вместе с message/usage; content_filter и
  неизвестный finish отклоняются. Исполнение tools в этом клиенте отсутствует.
- Реальное прерывание HTTP по context cancellation и deadline;
  отменённый до отправки запрос и output budget >4096 не отправляются;
  refused connection возвращает обезличенную ошибку и неизвестный usage.

Это локальные HTTP fixtures для контракта и воспроизводимых сбоев, а не
live evidence. Серверы слушают случайные loopback ports; БД не требуется.

## Live DeepSeek

Команда:

```sh
DEEPSEEK_MODEL=deepseek-flash DEEPSEEK_THINKING=disabled \
  python3 integration/deepseek.py --live \
  --env-file /home/kotdath/omp/personal/ai/paper-scout/.env
```

PASS: официальный `https://api.deepseek.com`, явная запрошенная модель
`deepseek-flash`, non-streaming, thinking disabled, три сетевых запроса,
без retries. Ключ загружен Go-процессом по пути; содержимое dotenv не читалось
агентом и не печаталось. В shared configuration модель отсутствовала:
первая попытка без явного override остановилась до сети с
`DEEPSEEK_MODEL is required`. Модель выбрана по актуальной официальной
документации и передана окружением без изменения shared dotenv.

| Вызов | Проверенный результат | Prompt | Completion | Total |
| --- | --- | --- | --- | --- |
| Plain, max_tokens=96 | Точный маркер `T03_OK` | 11 | 3 | 14 |
| Tools, max_tokens=256 | Вызов multiply с проверенными аргументами 6 и 7 | 313 | 53 | 366 |
| Tool result, max_tokens=64 | Локально вычисленное 42 передано с исходным tool_call_id; итог `42` | 379 | 1 | 380 |

Итого: 703 prompt + 57 completion = 760 tokens. Провайдерные тела и reasoning
в артефакты не записывались. Live thinking-enabled обмен не проверялся;
replay соответствующего поля проверен HTTP fixture. Реальные 429/5xx,
ошибки ключа/баланса специально не провоцировались: они проверены fixture.

Первый локальный build встретил TLS handshake timeout при загрузке godotenv;
повторная сборка и интеграционная проверка прошли. Это внешний временный сбой,
не успешная проверка первой попытки.

## Проверка упрощения

После двух одобренных ревью проверен весь diff от указанного base; переданный
`simplify.patch` совпадает с исходниками на `436c2ee` (кроме завершающего
перевода строки). Лишних сущностей или полезного сокращения не найдено:
единственный HTTP-клиент не владеет историей, tools или retry loop.
`Function` описывает инструмент, а `FunctionCall` — вызов со строкой arguments;
это разные части протокола. Отдельный wire usage с указателями необходим,
чтобы отличать отсутствующий счётчик от нуля. Локальные wire structs не
дублируют публичные серверные контракты. Объединять fixture и live exchange
в общий сценарий не требуется: они проверяют разные границы.

Код оставлен без изменений; поведение сохранено точно. Повторно выполнены
`python3 integration/deepseek.py`, `go build -o .bb/runtime/t03/bin/ ./...`,
`go vet ./...`, проверка gofmt и `git diff --check` — PASS. Caches, build
outputs и временные файлы направлены внутрь этого worktree. Отслеживаемых
unit/widget tests нет. Оплачиваемые запросы не повторялись: выше сохранены
live evidence и ограничения проверки неизменённого клиента.
