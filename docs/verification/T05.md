No successor-node functionality is claimed.

Implemented `internal/documents`, `T05_documents.sql`, executable integration
checks and [the module contract](../documents.md). HTML-first ingestion falls
back to PDF, then explicitly labeled abstract/failed. It stores complete
extracted text, source SHA-256, extractor/chunking versions, sections/pages,
Unicode offsets, stable evidence IDs and warnings. Sources are bounded official
arXiv HTTPS URLs; subprocesses use fixed arguments and context deadlines.
Source files are private and atomically cached; document/chunks commit together.
Repeated successful import uses the persistent cache without a network request.

## Limitations and integration boundaries

- Earlier real PDF attempts for `2304.03442v1` (11,832,276 bytes) and
  `1706.03762v1` (2,128,686 bytes) did not complete within the 60-second download
  budget and returned `source_unavailable`; they were not counted as successful
  PDF evidence. The final small PDF (109,440 bytes) passed without increasing
  production resource limits. HTML for the memory-agent article succeeded.
- T04 is parallel, not a dependency. The integration executable creates only
  the `paper_versions.id` catalog reference fixture; actual T04 catalog/schema
  composition is not verified here. Production T05 creates no metadata entity.
- Ownership grants/API, FTS/embeddings, full model reading/coverage belong to
  subsequent nodes. `full_text` here means extracted text, never model coverage
  `complete`. Callers must check membership/run ownership before exposing it.
- No OCR, image/formula interpretation or reliable table reconstruction. Blank
  or sparse PDF pages and replacement characters have explicit warnings.
  Long-running Poppler kill behavior was not stress-tested; fixed-argument
  commands are context-bound, stdout limits and pre-execution deadline checked.
- Runtime documents, databases and binaries stay under ignored `.bb/runtime/t05`
  and disposable check directories are removed. No PDF, credentials or private
  reasoning is included in Git. No device/UI interaction was needed for T05.
