## Integration — PASS

`python3 integration/agent.py` builds with `-race` and exercises the real
DeepSeek HTTP client, SQLite, research lifecycle, registry and session together.
External-provider HTTP fixtures use ephemeral loopback ports and temporary DBs.
They are not live DeepSeek evidence.

- Model → real owner-scoped profile tool → model; original call IDs and private
  reasoning replay; complete follow-up history; foreign owner/conversation and
  duplicate terminal start rejected without provider replay.
- Unknown tools, malformed/null JSON and owner injection return structured
  errors without execution. Public events omit fixture reasoning and foreign
  profile content never enters provider context.
- Truncated responses never execute tools, preserve usage and record skipped
  calls. Failed turns are excluded from subsequent context.
- Request/tool/context/actual-token limits; identical calls execute at most
  twice. Nested model requests share the same request/token budget.
- Cancellation during a two-call assistant turn skips the second tool with its
  original ID. Cancellation of an actual in-flight HTTP request preserves
  unknown usage. Overall duration and tool deadlines propagate correctly.
- Retryable HTTP 503 succeeds on one bounded retry; persistent 503 stops after
  two attempts. Unknown token reservations remain distinct from actual usage.
- Successful finalization callback commits terminal state; an uncommitted
  callback is rejected. SQLite integrity passes; reopening preserves completed
  history and recovers an unfinished request reservation as interrupted.
